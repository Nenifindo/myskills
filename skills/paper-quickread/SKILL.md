# 论文速读

面向“快速理解一篇论文”的单份中文报告技能。重点回答三个问题：为什么要做（Motivation）、提出了什么（Idea）、如何证明有效（Evaluation）。

## 输入与取证

- 支持本地 PDF 和论文 URL。先确认来源、标题和版本；URL 需要在可行时获取 PDF 或正文。
- 输入为 arXiv 的 `abs`、`pdf`、`html` 链接或论文 ID 时，视为可以获取同版本的 LaTeX 源码。运行 `python3 <本 skill 目录>/scripts/prepare_arxiv_figures.py <arxiv-url-or-id> --output-dir <临时目录>`，用生成的 `figures-manifest.json` 定位源码图片；链接显式包含 `vN` 时不得混用其他版本。
- 优先使用论文原文，至少覆盖摘要、引言、方法、实验、消融和结论。超长论文先读摘要/引言/结论建立主线，再回看方法与实验关键段落。
- 对方法框架图、关键表格、消融结果等影响结论的图表，进行必要的视觉或文本核对。
- 结合图片所在章节、正文引用、LaTeX caption/label 和视觉内容判断图意。不要仅凭文件名选图；manifest 中 unresolved 的条目不可直接写入报告。
- 原文不足时，仅在术语、关键前置工作或动机缺口确实需要核实时做有限外部检索，并在报告中标注“外部来源”。
- 任何无法确认的内容写成“论文未说明”或“根据文中信息推断”，禁止补造作者、配置、baseline、指标或结果。

### arXiv 插图

- 只选择能推进理解主线的最少图片。优先考虑揭示关键矛盾的动机图、方法总览图、主实验图和关键消融图；跳过 logo、纯装饰、独立 legend、重复子图和在报告尺寸下不可读的图片。
- 将选中的可显示图片复制到报告同目录的 `assets/`，并使用相对路径引用。PNG/JPEG/GIF/WebP/SVG 可直接使用；PDF/EPS 等格式优先使用脚本从 arXiv HTML 匹配到的 SVG/PNG 衍生图，其次再用本地工具转成 PNG。只允许格式转换和必要的空白裁剪，不得改变数据或图中标注。
- 插图紧跟第一次深入解释它的段落：动机图放在现象或矛盾分析后，方法图放在“整体直觉”后，实验图放在对应实验分析附近。每张图都提供有信息量的 alt text，并在图后写明“来源：原论文 Figure N”及一至两句读图要点；Figure 编号须由论文正文或 HTML 核对。
- 图片不能替代分析，也不要求覆盖论文的所有 Figure。若源码、HTML 衍生图、格式转换或语义匹配失败，记录原因并继续基于 PDF 生成文字报告；不得生成不存在、不可显示或指向临时目录的图片链接。

## 内部分析方法

先建立不直接交付的分析链，再写报告：

1. 提取论文要解决的任务、已有方案、核心瓶颈、观察到的证据和研究目标。
2. 将每个方法机制映射到它要解决的具体问题，并记录输入、处理、输出及与 baseline 的差异。
3. 区分主实验、消融、对比、鲁棒性和效率证据。
4. 标记每条结论的证据位置（章节、图表、表格或实验），并区分原文事实、通俗解释、合理推断和未证实猜测。
5. 对候选插图建立“图片—论点”映射，只保留能够直接解释某个关键论点或证据结论的图片。

## 输出要求

默认生成中文 Markdown 文件，并在对话中给出一句话摘要。保留模型名、数据集名、方法名、指标缩写等英文原名；首次出现的关键术语提供简短中文解释。

报告必须遵循 [references/report-template.md](references/report-template.md) 的结构，包含：

- 核心结论速览
- 论文基本信息
- Motivation：背景、已有进展、瓶颈/矛盾、论文观察、问题推导、研究目标与假设
- Contribution 👉 Idea：整体直觉、逐机制拆解及与 baseline 的区别
- Contribution 👉 Evaluation：数据集、baseline、各类实验分析
- 最后小结
- 术语速查

## 写作标准

- 用“问题链”和“因果链”组织内容，不做线性翻译或术语堆砌。
- 技术细节只保留理解主线所需的部分；公式先解释其在机制中的作用，再决定是否保留。
- 重点写趋势、相对结论和证据是否覆盖机制；性能数字只在支撑结论必要时保留，避免把数字涨幅当成主体。
- 如果报告依赖外部资料，单独标记其来源和用途，不让外部信息冒充论文结论。

## 交付

文件名建议为 `[论文简称].md`，图片目录为同级的 `assets/`。生成文件后检查 Markdown 可读性、每个相对图片路径及图片可显示性，并在回复中简要说明论文的核心问题、Idea 和证据结论，同时提供报告文件链接。
